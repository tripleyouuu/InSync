# InSync

InSync is an iOS app that helps you keep track of the schedules of everyone in your life — friends and family — across different time zones, so you can check at a glance who's free for a quick chat right now.

## Why InSync?

Staying in touch with people spread across the globe means constantly doing time-zone math in your head: *"Is it too early to text Mom? Is my friend in India done with school yet?"* InSync takes care of that for you by giving you a single view of everyone's local time and likely availability.

### Requirements

- Xcode (latest stable version recommended)
- iOS device or simulator running iOS 26.0 or later.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/tripleyouuu/InSync.git
   ```
2. Open the project in Xcode:
   ```bash
   cd InSync
   open CH2_Master.xcodeproj
   ```
3. Select a simulator or connected device as the run target.
4. Build and run (`⌘R`).

## Project Structure

```
InSync/
├── CH2_Master.xcodeproj   # Xcode project file
└── CH2_Master/            # App source code
```

## Usage

1. Launch the app.
2. Add the people you want to track, along with their time zone.
3. Open the main screen to see everyone's current local time and availability at a glance.
4. Reach out to whoever's free!
